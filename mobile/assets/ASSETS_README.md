## Required Assets

Before building, create or place these files in this directory:

- `icon.png` — 1024×1024 app icon
- `adaptive-icon.png` — 1024×1024 Android adaptive icon foreground
- `splash.png` — 1284×2778 splash screen image (centered logo on transparent)

For development builds, blank placeholder images will work. For production,
use properly designed assets that match the RupayAid brand.
